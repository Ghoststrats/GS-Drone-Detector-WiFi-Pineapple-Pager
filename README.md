# GS-Drone-Detector-WiFi-Pineapple-Pager
The payload uses the WiFi Pineapple Pager's wireless scanning capabilities to identify nearby Wi-Fi networks with drone-related names, such as DJI, Autel, Parrot, and FPV.  When a possible match appears, it displays a live signal-strength bar, monitors changes in received signal strength, and requests sound and vibration alerts from the Pager.
